최근 10일 쇼핑 데이터로 추천 상품 8개를 고르고, 쇼츠 영상을 자동으로 만들어 SNS 에 올려 주는 Windows 앱

Windows 용 다운로드

최신 버전 · Windows 10 / 11 (64비트) · 약 95MB

휴대폰에서는 설치할 수 없습니다. 이 주소를 PC 에서 열어 내려받아 주세요.

설치 방법

  1. 위 Windows 용 다운로드 버튼을 눌러 설치 파일을 받습니다.
  2. 받은 ShoppingShortsStudio-Setup.exe 를 실행합니다.
  3. 파란 창(Windows 의 PC 보호)이 뜨면 추가 정보 → 실행 을 누릅니다. 새로 나온 앱이라 처음에 한 번 나올 수 있습니다.
  4. 설치가 끝나면 바탕화면의 아이콘으로 앱을 엽니다.
  5. 처음 화면에서 구매할 때 받은 라이선스 키를 넣습니다.

업데이트

  • 한 번 설치하면 다시 받을 필요가 없습니다. 앱의 관리 → 업데이트·라이선스 화면에서 새 버전을 확인하고 바로 설치할 수 있습니다.
  • 앱 안의 프로젝트·설정·연결 정보는 업데이트해도 그대로 남습니다.

자주 묻는 질문

  • Mac 이나 휴대폰에서도 되나요? 지금은 Windows PC 전용입니다.
  • 라이선스 키를 잃어버렸어요. 구매하신 곳으로 문의해 주세요.
  • 다운로드가 막혀요. 브라우저 다운로드 목록에서 유지 또는 계속 을 눌러 주세요.

설치 파일은 GitHub 에 보관되며, 버튼은 항상 최신 버전을 받습니다.
